Pipeline briefing · 11

Staff questions — short answers

  • Whole-corpus agent search? No — strong seed first; ≤2 rounds.
  • Why MiniLM+BGE? Cheap shortlist → accurate refine; order matters.
  • Hard domain filter? No — misroute refusals; use 80+20.
  • FAQs deleted? No — excluded at retrieve only.
  • Why ~25–45s? CE + agent + answer ≈ thirds; verify +1.5s.
  • Citations? USED_PASSAGES indices → file+page.
  • Verify in prod? Recommended opt-in — 91.7% / 83.6% measured.
  • Grep? Off — regressed 48Q.
  • Chunk size? Pack 500 / max 700; window=2 neighbors.

03 · Ingestion

Chunking: structural pack, not sliding window

  • Docling hierarchy → section / clause / subclause
  • Pack toward target_tokens=500, hard max=700
  • Fold parent+children when they fit; pack sibling leftovers
  • Split only when a node exceeds max
  • No token-overlap sliding window

Context at retrieve time comes from --window 2: ±2 same-file neighbor chunks by sequential id.

Why this shape

Insurance PDFs are hierarchical. Sliding windows smear clause boundaries and duplicate headers. Structural packs keep “one idea ≈ one chunk” and preserve page lists for citations.

Key files: rag/chunk.py, rag/corpus_chunks.py, rag/txt.py

03 · Design choice

Exclude FAQs at retrieve (keep in index)

Problem

Scraped */pages/faq.txt are mostly question titles with almost no answers. Dense retrieval loved them — high lexical overlap, empty evidence.

Decision

Default: filter FAQ files out of the candidate pool (is_faq_file). Opt-in via --include-faq. Still indexed if we ever want them.

Same class of choice as “don’t let marketing blurbs crowd out policy PDFs.”

05 · Router

Domain router: 80 routed + 20 global

Gemma picks 1–3 of 12 domains before dense search.

  • Rejected Pure domain filter → 81.2%, refusals on misroute
  • Kept 80 from routed domains + 20 unique global
  • Kept --route-context: dense preview feeds the router

Why hybrid, not hard filter

Apartment questions sometimes need health / claims booklets. A hard domain gate caused empty refusals. The global leg is the safety valve; the routed leg is the precision boost.

09 · Deep dive

Why verify/strip failed

Design

Gate → tiny Gemma on cited passages → delete unsupported sentences → no regen.

Reality (48Q)

87.5% → 68.8%. Fixed ~1 Q; regressed ~10. Stripped GT numbers/conditions when under-cited or misjudged.

  • Gate too wide (used_tools ≈ always on for agent)
  • Evidence too narrow (cited only ≠ true)
  • Sentence-level delete removes the asked fact with the extra
  • No “still answers the question?” revert check
09 · Deep dive

Why agent-grep / few-shots failed

  • Grep returns hits, not attached text — needs fetch_chunks
  • Controller often grepped answer-shaped phrases
  • Burned rounds even when seed was enough
  • Few-shots improved query shape on smoke, hurt full 48Q

11 · Principles

Design principles that stuck

  • Structure over windows for insurance PDFs
  • Dual-rep tables — search NL, answer CSV
  • Soft route — precision + global safety
  • Exclude empty FAQs from retrieve
  • Catalog for products, dense for clauses
  • Cheap CE → strong CE, never reverse
  • Agent on a good seed, not agent as search
  • 2 rounds max — more tools ≠ more OK
  • Passage cite over path soup in the body
  • Measure strip before shipping — verify taught that
